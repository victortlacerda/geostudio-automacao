# Exemplos oficiais da API

Copie aqui os scripts de exemplo que vêm com o GeoStudio 2026.1 (o `procurar_instalacao.txt` mostra
onde estão). São a fonte mais confiável dos nomes da API, como o histórico de comandos no PLAXIS.
Confira a licença de uso antes de publicar: se não puderem ser redistribuídos, mantenha só a lista
de nomes e o que cada um faz neste README.
